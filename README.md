# json-flatten
json-flatten — flatten nested JSON to dot-notation keys (e.g., {'user.name':'Alice'}). Handles arrays with index notation.

Part of [supercli](https://github.com/javimosch/supercli) ecosystem.

```bash
curl -LO https://github.com/javimosch/json-flatten/releases/latest/download/json-flatten-linux-amd64
chmod +x json-flatten-linux-amd64; sudo mv json-flatten-linux-amd64 /usr/local/bin/json-flatten
```
